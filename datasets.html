Flagship dataset

CAMELS-IND

Catchment Attributes and Meteorology for Large-sample Studies – India. Daily meteorological time series, observed and LSTM-predicted streamflow, and static catchment attributes for 472 catchments in Peninsular India — designed to foster large-sample hydrological studies and bring Indian catchments into global research.

Data, Models & Software

Sharing our model codes, data, results and analysis notebooks.

MM_Ensemble-for-Flood-Mapping

A Novel Multi-Model Ensemble Framework for Fluvial Flood Inundation Mapping. This code contains machine learning-based multi-model ensemble framework for fluvial flood inundation mapping.

GitHub ↗

Differentiable hybrid models

Differentiable Parameter Learning (dPL) + HBV Hydrologic Model with Reservoir Module. In this version, we have extended the model by incorporating a reservoir module, enabling simulation of regulated catchments. This enhancement allows the model to better represent flow dynamics influenced by reservoir operations.

Zenodo ↗

PIDuaL: Physics-Informed Dual-Output LSTM

PIDuaL is an extension of the Mass-Conserving Long Short-Term Memory (MC-LSTM) model for hydrological modeling. It enables the simultaneous prediction of streamflow and evapotranspiration through a modified water-balance structure.

Zenodo ↗

Benchmarking Conceptual Rainfall–Runoff Models

This dataset accompanies the manuscript “Benchmarking and Selecting Optimal Hydrological Models for Large-Sample Applications Considering Complexity and Uncertainty” (Mangukiya et al., under review, Water Resources Research). It provides simulated streamflow outputs and evaluation metrics for 47 conceptual rainfall–runoff models applied across 159 watersheds in Peninsular India.

Zenodo ↗

Net Primary Productivity (NPP) data

Monthly, Seasonal and Yearly Net Primary Productivity (NPP) data of India from 2003-2020 modelled using the CASA model.
